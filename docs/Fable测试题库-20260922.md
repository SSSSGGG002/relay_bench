# Fable 5.1 中转站测试题库（relay-bench，整理于 2026-09-22）

这份题库是我们给各家中转站的 `claude-fable-5-1` 做鉴定用的，分四块：**知识前沿**（定型号，最关键）、**年代探针**（辅助定型号）、**身份/隐藏 prompt 探针**（看中转层）、**智力题**（看能力档位）。
所有智力题答案都是程序算出并验证过的，知识题答案 2026-09-09 按维基/官方公告核过。

## 0. 怎么用（先看这段）

1. **模型自报的名字、厂商、截止日期一律不采信。** 我们做过对照：签名验证过的真 Fable 5.1，在 Kiro 风格 system prompt 下会自称 "Sonnet 4.5 / 2025-01"，在 Claude Code 里自称 "Fable 5.1 / 2026-06"，没有 prompt 时说 "unknown"。自报完全跟着 prompt 走，Claude Code 环境下更是必然「正确」。
2. **定型号靠知识前沿。** 官方模型对标称截止前 4–6 个月的事都大量答 UNKNOWN，所以不能拿标称截止日期硬比，要拿**官方同型号的实测答案**逐题比：官方知道而它不知道 = 疑似降级；它知道而官方不知道 = 映射到别的模型。下面每题都附了官方 Fable 5.1（订阅直连 `claude -p`，2026-09-10 实测）的答案。
3. **单次结果有采样噪声，决定性题目每题重复 3 次以上**，官方稳定答对而中转稳定 UNKNOWN 才算定案。号池混合时按响应 id 分族（`msg_011C…` 官方 id / `msg_pre_…` / 随机 id）分别统计，不要把混池平均。
4. 建议顺序：先跑「快筛」（身份 5 题 + 年代探针 10 题 + screen 8 道智力题，约 30 次调用、3 分钟），淘汰明显假货；通过的再跑全量知识阶梯和 26 道智力题。
5. 请求参数：知识题 `max_tokens 500`、关思考（或中转允许的最小 effort）；智力题开思考、`max_tokens 6000–16000`（难题会烧 1–2 万输出 token）。流式和非流式各测一遍，很多站两种模式落不同池。

## 5. 其他配套测法（一句话版）

- **验签**：开思考拿到 thinking 块后，把它原样 / 改签名末 6 位 / 删签名 / 改思考正文 / 整段伪造签名，作为历史消息回传。真 Anthropic 上游：改签名与伪造签名必 400，原样 200；四种全 200 = 中转不把 thinking 送上游（Kiro/适配器）。

- **速度**：流式写 700 词作文，记 TTFT、正文 tok/s、每 chunk 字符数（真流式 2–4 字符/chunk，假流式一次性大块）。
